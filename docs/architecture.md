# 系统架构详解

## 总览

五行飞轮是一个 16-Agent 认知对抗分析系统：

- **5 节点Agent**：青龙(木)、朱雀(火)、谛听(土)、白虎(金)、玄武(水)
- **10 边Agent**：5个相生边 + 5个相克边
- **1 仲裁Agent**：天鲸(SkyCetus Kernel)

## 数据流

```
用户输入主题
    ↓
┌─────────────────────────────────────────┐
│ Round N (多轮迭代)                       │
│                                         │
│  青龙 ──木生火──→ 朱雀                   │
│    ↑               │                    │
│  水生木           火生土                  │
│    │               ↓                    │
│  玄武 ←──金生水── 白虎 ←──土生金── 谛听   │
│    │                                    │
│    └── 收敛判定 ──→ 继续/停止            │
│                                         │
│  同时运行相克链:                          │
│  木克土, 土克水, 水克火, 火克金, 金克木    │
│                                         │
└─────────────────────────────────────────┘
    ↓
天鲸仲裁 → 最终评分 → 报告生成
```

## 模型路由

飞轮支持多模型路由，每个Agent可以使用不同的LLM：

```python
MODEL_ROUTING = {
    "qinglong": "deepseek",    # 发散任务用高创造力模型
    "zhuque":   "deepseek",    # 分析任务用强推理模型
    "diting":   "kimi",        # 校验任务用准确性模型
    "baihu":    "deepseek",    # 对抗任务用强逻辑模型
    "xuanwu":   "deepseek",    # 收敛任务用综合能力模型
    "verifier": "kimi",        # 评分用独立模型
}
```

路由可根据需要替换为任何 OpenAI-compatible API。

## 收敛机制

每轮迭代后，verifier评估整体质量：
- score ≥ 0.80 → 停止迭代
- score < 0.80 且 轮间delta < 0.03 → 停止（收敛饱和）
- 最大轮次：3轮（deep模式）/ 1轮（quick模式）

## 知识树

每次分析完成后，自动提取：
- **实体**（concepts, technologies, companies）
- **关系**（enables, competes_with, requires）
- **结论**（validated conclusions with confidence）

知识树驱动 gap_detector，发现知识缺口后自动触发新的飞轮分析。

## 报告模板

最终报告包含：
1. 一句话结论
2. 核心矛盾
3. KPI面板
4. 研究边界
5. 鲲鹏结论（鲲潜·鹏举·合流）
6. 佛家三时评估
7. 精神三层分析
8. 战略建议
9. 风险提示
10. 五行过程详情（可折叠）
