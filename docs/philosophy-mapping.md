# 五位思想家 × 五行映射

## 核心映射

| 五行 | 思想家 | 核心智慧 | 认知功能 |
|------|--------|----------|----------|
| 木 Wood | 道家 Daoism | 自然发散，观察先于判断 | 生成假设、种子发散 |
| 火 Fire | 第一性原理 First Principles | 烧掉表象，还原本质 | 证据分析、深层推理 |
| 土 Earth | 儒家 Confucianism | 知行合一，格物致知 | 交叉验证、事实校准 |
| 金 Metal | 弗洛伊德 Freud | 揭露无意识偏见 | 对抗攻击、深层审查 |
| 水 Water | 佛家三时 Buddhism | 过去·现在·未来的因果观照 | 收敛综合、种子回生 |

## 为什么是这五位？

不是因为他们"正确"。是因为他们代表了五种**不可还原的认知模式**：

1. **道家 → 发散**：不预设答案，让答案自然涌现
2. **第一性原理 → 还原**：层层剥离，找到不可再分的基岩
3. **儒家 → 验证**：理论必须经得起实践检验
4. **弗洛伊德 → 对抗**：审查思维过程本身的偏见
5. **佛家 → 时间**：在时间维度上观察因果

五种模式互相独立，任何一种都不能被其他四种替代。

## 相生链（生成循环）

```
道家发散 → 第一性原理还原 → 儒家验证 → 弗洛伊德对抗 → 佛家收敛 → 道家发散
木生火    → 火生土          → 土生金    → 金生水          → 水生木
```

每个环节的输出成为下一个环节的输入：
- 道家生成的假设 → 被第一性原理烧炼
- 烧炼后的分析 → 被儒家校验
- 校验后的结论 → 被弗洛伊德攻击
- 攻击后的残差 → 被佛家收敛
- 收敛产生的新种子 → 回到道家继续发散

## 相克链（制衡循环）

```
道家 → 克儒家：发散打破秩序的固化
儒家 → 克佛家：实践检验超越性思维
佛家 → 克第一性原理：无常性挑战永恒假设
第一性原理 → 克弗洛伊德：理性还原对抗过度解读
弗洛伊德 → 克道家：揭露"自然"背后的无意识投射
```

## 图论证明

5是实现双独立循环（相生+相克）的最小节点数。

- 3个节点：只能形成一个循环
- 4个节点：两个循环必然共享边
- 5个节点：五边形（相生）+ 五角星（相克）= 两个完全独立的哈密顿回路

这不是巧合——中国古人的五行理论恰好对应了图论中的最小双循环拓扑。
