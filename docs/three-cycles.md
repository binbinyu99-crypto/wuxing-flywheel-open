# 三大循环理论

## 元素循环（微观）

五行相生相克，是飞轮的基本运转机制。

**相生（生成链）**：木→火→土→金→水→木
- 每个元素的输出成为下一个元素的输入
- 完成一圈 = 一轮分析迭代

**相克（制衡链）**：木→土→水→火→金→木
- 独立于相生链运行
- 提供交叉检验和纠错

## 元循环（中观）

五位思想家的哲学视角注入每个Agent的推理过程。

不是"用AI模拟哲学家"，而是"让哲学家的认知模式成为AI的思维基础设施"。

| Agent | 哲学注入 | 效果 |
|-------|---------|------|
| 青龙 | 道家观察方式 | 种子不是"想"出来的，是"看见"的 |
| 朱雀 | 第一性原理还原 | 分析不在中间层偷懒 |
| 谛听 | 儒家知行合一 | 理论必须对接现实 |
| 白虎 | 弗洛伊德三我审查 | 攻击思维过程而非仅攻击结论 |
| 玄武 | 佛家三时因果 | 在时间维度上检验收敛 |

## 大循环（宏观）

六段闭环，连接系统与外部世界：

```
知识树 → 飞轮分析 → Agent执行 → 外部反馈 → 谛听采集 → 知识树更新
  ↑                                                          |
  └──────────────────────────────────────────────────────────┘
```

### 六段诊断

1. **知识树→飞轮**：gap_detector检测知识缺口，自动触发分析
2. **飞轮→Agent执行**：16个Agent完成多轮迭代分析
3. **Agent执行→外部发布**：自动发布到飞书文档 + 网站
4. **外部世界→谛听采集**：diting_collector定期采集外部信号
5. **谛听→知识树**：采集结果写入知识树实体和关系
6. **知识树→新分析**：新知识产生新的gap，触发下一轮飞轮

大循环一旦转动，系统就具备了自我进化能力。
